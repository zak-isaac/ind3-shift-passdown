How Repair Causes Get Added to Shift Reports

We get two files every shift: one with what the tech wrote, and one with what actually caused the problem. This shows how those two get matched up and turned into one clean line in the report.

Routine maintenance never shows up as a "problem"

We check for routine scheduled maintenance TWICE — once in the timecard file and once in the cause file — so it can never accidentally show up as an issue. It only ever shows as a total count at the top.

The two files stay separate until the very end

The tech's notes and the repair-cause notes are kept apart the whole time. They only get matched together, by Work Order number, at the moment the report is actually built.

Nothing breaks if a file is missing

If no cause file gets uploaded, or a Work Order just doesn't have a match, the report looks exactly like it always has: Asset name, then what the tech did.
